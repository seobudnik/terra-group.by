# Terra Group — практика и стажировка в event

HTML-лендинг образовательного контура агентства: учебная практика, летняя стажировка, помощник на проекте.

## Секции (главная — практика)

1. Hero (бренд, оффер практики, CTA)
2. Чему научитесь (бриф → площадка → день события → пост-отчёт)
3. Об агентстве
4. Форматы
5. Для вуза (дневник, отчёт, темы диплома)
6. Заявка + контакты
7. Футер

## Услуги

- [`services/kommercheskie-sobytiya.html`](services/kommercheskie-sobytiya.html) — коммерческие события / BTL  
  Целевой URL: `https://www.terra-group.by/services/kommercheskie-sobytiya.html`

## Старт

1. Бриф — [`БРИФ.md`](БРИФ.md)
2. Тексты в `index.html`, цвета в `:root` (`styles.css`)
3. Фото в `assets/`
4. Открыть `index.html` в браузере

## Медиа

- `hero.jpg` — сцена / backstage
- `team.jpg` — команда или площадка
- `topic-1.jpg`, `topic-2.jpg` — блок «Для вуза»

Без файлов остаются градиенты.
